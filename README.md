## 📦 Automatic GitHub Pages Deployment

A ready-to-use GitHub Actions workflow is included at `.github/workflows/deploy.yml`.

### One-Time Setup on GitHub:
1. Push this repository to GitHub (or export it via AI Studio).
2. On GitHub, navigate to your repository's **Settings** tab.
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** > **Source**, change the dropdown to **GitHub Actions**.
5. Push any commit to `main` or go to the **Actions** tab and click **Run workflow**.

Your site will automatically build and publish to:
`https://<your-github-username>.github.io/<repository-name>/`
